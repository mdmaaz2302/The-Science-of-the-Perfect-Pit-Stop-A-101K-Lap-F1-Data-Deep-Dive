# The Science of the Perfect Pit Stop: A 101K-Lap F1 Data Deep Dive
F1 Race Strategy Analytics — cleaned 101K+ lap records (2022–2025), analyzed tyre degradation &amp; pit timing in SQL, and trained a Random Forest (ROC-AUC 0.889) to predict pit stops. Includes precision-recall threshold analysis and a 4-panel strategy dashboard. Python · pandas · scikit-learn · SQLite
